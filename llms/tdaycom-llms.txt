# tday

> tday (tday.com) is a Y Combinator-backed (Spring 2026) AI platform that turns a software product into on-brand marketing content. It connects to a company's GitHub repository or live website and, on every release, produces a launch package — a demo video generated from real product flows, feature showcases, and on-brand social graphics and ads — then publishes and measures that creative across social and ad channels. tday exposes a hosted Model Context Protocol (MCP) server as its agent-facing surface.

This llms.txt was generated by the API Evangelist enrichment pipeline from the tday public surface and the artifacts in this repository. tday publishes no official /llms.txt.

## MCP

- [tday MCP server](https://tday.com/api/mcp): Hosted Model Context Protocol server, OAuth 2.1 secured (authorization_code + PKCE, dynamic client registration, scope "tday"). Returns 401 to unauthenticated requests.
- [OAuth Authorization Server metadata](https://tday.com/.well-known/oauth-authorization-server): RFC 8414 discovery document.
- [OAuth Protected Resource metadata](https://tday.com/.well-known/oauth-protected-resource): RFC 9728 discovery document (resource = https://tday.com/api/mcp).
